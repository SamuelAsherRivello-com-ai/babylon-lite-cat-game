# Cat Hangout asset provenance

The game copies the following user-supplied assets from `CatMegaFree` into `cat-hangout/public/assets/catmega/`:

- `PochiFree/FreeSprites.png` as `pochi-sprites.png`
- `MochiFree/Idle.png` as `mochi-idle.png`
- `MochiFree/Box3.png` as `mochi-box.png`
- `CatRoomFree/Furnitures.png` as `furniture.png`

The source folder did not include a license or attribution file. Public release remains blocked until the asset owner supplies usage and attribution terms. The built game reads only these project-local copies.
